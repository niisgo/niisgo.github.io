# Nico Tillmann — Portfolio

Personal developer portfolio built with **Angular 17** (standalone components).  
Live: [niisgo.github.io](https://niisgo.github.io) 

---

## Schnellstart lokal

```bash
# 1. In den Ordner wechseln
cd nico-portfolio

# 2. Abhängigkeiten installieren (einmalig)
npm install

# 3. Dev-Server starten
npm start
# → http://localhost:4200
```

## Stack

- **Angular 17** · Standalone Components · Signals
- **SCSS** · CSS Custom Properties
- **Google Fonts**: Fraunces, Outfit, JetBrains Mono
- Kein externes UI-Framework
- Deployed via **GitHub Actions → GitHub Pages**
- DSGVO-konform: kein Tracking, keine Cookies
